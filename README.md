# SIGNAL ARENA — карта проекта

Единственный игровой клиент — **`phaser/`** (Phaser + TypeScript + Vite, стек по ТЗ `new.txt`).
Единственный сервер — **`backend/`** (модуль `aibackend`: движок, контент, API).

| Папка | Что это | Статус |
|---|---|---|
| `phaser/` | Игра: 12 сцен, механики M1–M15, эпохи I–IV, детерминированный движок | ✅ основной клиент, `npm run dev` → превью |
| `backend/` | Сервер: валидация попыток, прогресс, турниры, AI-пайплайн | ✅ логика готова; мост клиент→API — следующий шаг |
| `ui/` | Согласованные стайл-прототипы (эталон вида, эпоха «Улица») | референс для докраски |
| `game_characters/`, `logo/` | Арт-ассеты (враги, сцены, логотипы) | референс/исходники |
| `tz.txt`, `стиль_тон.txt` | Бриф и правила тона текстов | документы |

## Что удалено и где это искать
React-прототипы (визуальные демо согласованного дизайна) убраны из рабочей ветки,
чтобы в проекте была одна правда. Полные копии остались:
- в истории git: `30425ee` (frontend, граффити-стиль) и `42a92e6` (arena2/frontend);
- на GitHub в `hudyakovictor/arenaui`: `implement-web3-game-ui.zip`.
Восстановление при необходимости: `git checkout 30425ee -- frontend`.

## Эпохи оформления (ТЗ Часть 2)
Один скелет UI — разные токены: I «Улица» L1–20 (граффити/кислота — согласованный вид),
II «Кабинет», III «Терминал», IV «Система». Токены — `phaser/src/ui/palette.ts`.

## Запуск
```
cd phaser && npm i && npm run dev   # клиент, порт 3000
```
