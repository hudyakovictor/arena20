# Карта интерфейса SIGNAL ARENA — где искать ошибки

Документ для внешнего специалиста. Составлен по реальному коду ветки
`arena/01a06d9e-arena20`. Все пути — от корня репозитория.

> Важно: файлов `phaser/src/ui/arenaLayout.ts`, функций `calculateArenaLayout()`,
> `createDebugEpochSwitcher()`, `destroyFrom()`, `createBrowser()`,
> `createAnswerBlock()`, `createBottomNav()`, `this.COLORS` **в проекте больше нет** —
> код переписан. Если вам дали список с ними, он устарел.

## 1. Почему интерфейс «переключался то на один тон, то на другой»

Причина найдена и устранена. Было **два независимых источника цвета**:

| Источник | Акцент «Улицы» | Кто им красил |
|---|---|---|
| `phaser/src/ui/palette.ts` | `#c8ff00` кислотный лайм | все сцены (`buildPalette`) |
| `phaser/src/config/epochConfig.ts` | `#31D6C4` бирюза | `tokens` эпохи |

Плюс третий механизм рассинхрона: нижняя навигация брала эпоху из
`scene.registry`, который **каждая из 12 сцен выставляла вручную**. Если сцена
забывала обновить ключ, шапка рисовалась в цвете текущей эпохи, а навигация —
в цвете прошлой. Отсюда «половина экрана в одном тоне».

**Что сделано:** цвета остались только в `palette.ts`; из `epochConfig.ts`
удалены `tokens`, `crutches`, `nav` (они не применялись к отрисовке);
`registry` убран из всех 12 сцен, палитра берётся из прогресса игрока
(`shell.ts` → `currentPalette()`).

## 2. Главные файлы интерфейса

### Единый источник оформления
- **`phaser/src/ui/palette.ts`** — **единственное** место с цветами. 4 эпохи
  (`street`, `cabinet`, `terminal`, `system`), `buildPalette(epochId)`.
  Любой новый цвет добавлять только сюда.
- `phaser/src/ui/tokens.ts` — размеры: холст 390×844, кегль 12/14/16/20/28,
  отступы, тач-зоны (min 44), высоты шапки/навигации, длительности анимаций.
- `phaser/src/ui/text.ts` — типографские пресеты (`display/title/body/caption/num`).
- `phaser/src/ui/copy.ts` — **все тексты для игрока** (объект `T`). Строк в коде быть не должно.

### Каркас экрана (шапка + нижнее меню)
- **`phaser/src/ui/shell.ts`** — `renderTopBar`, `renderBottomNav`,
  `renderBackground`, `navForEpoch`, `currentPalette`.
  Здесь же `replaceChrome()` — защита от дублей панелей.

### Основной модуль — Арена
- **`phaser/src/scenes/ArenaScene.ts`** (~810 строк) — **самый нагруженный файл**.
  Оркестрирует экран: `buildLayout()` собирает блоки погоды, вопроса, угрозы,
  браузера, улик и кнопки действия; `rebuild()`/`clearContent()` — пересборка;
  `showEpochTransition()` — смена эпохи.
- `phaser/src/scenes/arena/SourceBrowser.ts` (~455) — вкладки источников, график, улики.
- `phaser/src/scenes/arena/DecisionPanel.ts` (~466) — карты, вердикт, варианты ответа, уверенность.
- `phaser/src/scenes/arena/FeedbackOverlay.ts` (~283) — итог встречи.

### Общие виджеты
- `phaser/src/ui/widgets.ts` — `button`, `panel`, `tappable`, `progressBar`, `chip`.
  **`tappable()` — частый источник багов с попаданием по кнопке.**
- `phaser/src/ui/ScrollList.ts` — скролл с инерцией. Вешает слушатели на
  `scene.input`; обязателен `destroy()`, иначе утечка.
- `phaser/src/ui/CandleChart.ts` — свечной график. При использовании внутри
  контейнера обязателен параметр `parent`, иначе рисуется мимо.
- `phaser/src/ui/motion.ts` — анимации, `transitionTo()` (переходы между сценами).
- `phaser/src/ui/feedbackFx.ts` — звук и вибрация.
- `phaser/src/ui/layout.ts` — `Flow` (вертикальная раскладка), `safeAreaInsets()`.

### Состояние и правила
- **`phaser/src/state/GameState.ts`** — `progress.level`, `progress.epoch`,
  `refreshEpoch()`, сохранение в localStorage (`arena_v5_progress`).
  **Если эпоха «скачет» — смотреть сюда в первую очередь.**
- `phaser/src/config/epochConfig.ts` — только границы уровней, имена и девизы эпох.
- `phaser/src/config/epochStructure.ts` — поведенческие отличия эпох
  (сколько вкладок, нужны ли подсказки, режим карт).
- `phaser/src/config/gameConfig.ts` — 390×844, `Scale.FIT`, список 12 сцен.
- `phaser/src/config/balanceConfig.ts` — баланс.

### Остальные экраны
`AcademyScene`, `CollectionScene`, `MoreScene`, `SettingsScene`, `StoreScene`,
`ErrorJournalScene`, `DailyWarmupScene`, `MasteryCheckScene`, `TournamentScene`,
`OnboardingScene`, `BootScene` — все в `phaser/src/scenes/`.

- **`ArenaScene.ts` ~810 строк** — стоит разделить: раскладка, поток шагов, оверлеи.
- В режиме «разбор» на экране 6 блоков сразу (погода, вопрос, угроза, браузер,
  улики, кнопка) — визуально перегружено, часть можно свернуть.
- Полоса улик имеет фиксированную высоту 34px при тач-минимуме 44.
- Бандл одним куском 1.82 МБ (423 кБ gzip) — нет код-сплиттинга.
- Клиент не подключён к 36 роутам API в `backend/` — данные локальные.
- Нет ESLint/Prettier и CI.

## 5. Как проверить

```bash
cd phaser
npm install
npm run typecheck   # tsc --noEmit, строгий режим
npm test            # vitest, 50 тестов
npm run build
npm run dev         # http://localhost:3000
```

Регрессионные правила интерфейса — `phaser/src/ui/__tests__/guardrails.test.ts`:
кегль ≥12px, тач-зоны ≥44, отсутствие меток «M1–M15»/«ТЗ», единственный
источник цвета, отсутствие `registry`, дублей каркаса и утечек ввода.
