## Нулевой вход → первый рабочий день

```
BootScene
  └─ (localStorage flag onboarding_done? нет)
     └─ OnboardingScene (3 шага: 33/33/33 → враги = твои ошибки → бюджет риска)
        ├─ «ДАЛЕЕ» ×2
        └─ «НАЧАТЬ» (или «пропустить») → setFlag(onboarding_done) → AcademyScene

AcademyScene (L4, эпоха УЛИЦА)
  ├─ список глав C1…C17 (открыты C1, C2 по уровню)
  ├─ тап по открытой главе → урок (overlay):
  │    атом-умение → микро-проверка (3 варианта) →
  │    верно → +1 ранг карты → «→ Арена»
  ├─ низ: Академия (активна) | Арена | Коллекция(locked) | Ещё(locked)
  └─ CTA «Продолжить урок → Арена» → ArenaScene

ArenaScene (задание из 4 блоков)
  ├─ TopBar (уровень/XP/SIG/БЮДЖЕТ РИСКА M15/свиток/погода)
  ├─ WeatherStrip M13 → QuestionPaper → UnknownThreat (силуэт «?», без раскрытия)
  ├─ BrowserShell (вкладки ≤3, источники) → EvidenceStrip M1
  ├─ CompactSkillCard (карты действий + ЖДАТЬ M10) → AnswerBlock (4 варианта)
  ├─ Confidence M3 (низко/средне/высоко) → submit
  └─ Feedback: M6 play-forward → M5 опознание (портреты-заглушки домена) →
       M14 тень арены → XP/SIG/бюджет → «ДАЛЕЕ → РАЗМИНКА»
       ↓
     (бюджет == 0 → Leviathan event; переход эпохи → EpochTransition)
```

## Взросление навигации (ось эпох, ТЗ Часть 2)

| Эпоха | Уровни | Доступно в низу | Доп. механики |
|---|---|---|---|
| I УЛИЦА | 1–20 | Академия, Арена | M1, M6, M10, M11, M12, M13, M15; M3 с L3; M5 с L8; M2 с L14 |
| II КАБИНЕТ | 21–50 | + Коллекция | M4 с L21, M7 полностью, M8, M9 с L30 |
| III ТЕРМИНАЛ | 51–80 | + Ещё (турниры/маркет) | все механики; ложные ярлыки в отдельных заданиях |
| IV СИСТЕМА | 81–99 | + Маркет, сезоны | смешанные встречи, тень, ложные ярлыки как норма |

Переход между эпохами — **событие** (поменялись токены, выросла навигация, снялись костыли). Ни одна механика М1–М15 не создаёт новую сцену.

## Как проверить весь путь в демо

1. **Сбросить** в `SettingsScene` («СБРОСИТЬ ПРОГРЕСС + ПЕРВЫЙ ВХОД») → вернёт к `OnboardingScene`.
2. Пройти онбординг → Академия → выдать карту (микро-проверка) → Арена.
3. В Арене решить задание: тапнуть **улику** в источнике (M1), выбрать **карту** (мост Академия→Арена), нажать **вариант** → **ставка** → фидбек с опознанием врага и тенью.
4. Кнопка **LVL+8** в Арене — прокачать эпоху и увидеть снятие костылей + рост навигации (Коллекция/Ещё).
5. Зайти в **Ещё** (More) → Свиток ошибок / Мастер-чек / Разминка / Турниры / Маркет / Настройки.

> Демо-прогресс уровня сохранён в `localStorage` (`arena_v4_progress`, `arena_v4_flags`). Сброс — в Настройках.
