# Signal Arena — Phaser 4.2.1 → v4 (Новая версия ТЗ)

Прототип доработан под **новую версию игры** (new.txt Части 1–6 + эпоховая система взросления).

## Что изменилось от скелета к новой версии

### 1. Архитектура данных (ТЗ Часть 4,6)
- `src/types/index.ts` — 17 карт C1…C17, 8 источников (Г,Н,П,К,Т,О,С,Сн), 33 врага E01…E33, стадии S1–S4, комбо K01–K17/T01–T08, EncounterInstance с seed.
- `src/data/cards.ts` — все 17 глав с уровнями открытия (L1,4,8,12…78), ранг-пороги, обязательные/допустимые источники.
- `src/data/enemies.ts` — полный реестр 33 врагов (6 осей доменов), палитры по эпохам, стадии как слои мастера + `secondDomain` на S3.
- `src/data/sources.ts` — 8 виджетов, правила ≤3 вкладок.
- `src/data/templates.ts` — шаблоны «учебная цель → ситуация → атомы → источники → враг → вопрос → 4 варианта + 3 дистрактора с типом ошибки → улики → play-forward».
- `src/config/balanceConfig.ts` — единый версионируемый JSON: риск-бюджет, evidence, sequence, confidence, verdict, blind, coldHead, combo, weather (конфиг vs концепция).
- `src/config/epochConfig.ts` — 4 эпохи (Улица/Кабинет/Терминал/Система), токены оформления, навигация как ось взросления, снятие костылей `есть→условный→нет→ложный`.

### 2. Детерминированный движок (Часть 6)
- `src/engine/rng.ts` — `SeededRng` xorshift32, один seed → один экземпляр на клиенте и сервере.
- `src/engine/mutator.ts` — оси мутации: актив, таймфрейм, зеркало, числа, формулировка, порядок; постусловие валидатора.
- `src/engine/scoring.ts` — XP/coins/бюджет по формуле `baseLoss × confidenceMul × domain`, защита M1 (необоснованно → неполная награда, враг не побеждён).
- `src/state/GameState.ts` — прогресс, уровень/XP/эпоха, ранг карт, свиток ошибок M7, калибровка M3, локальный `schedule_queue`, офлайн-очередь `AttemptQueue`.

### 3. Механики M1–M15 как состояния блоков (Часть 3)
Ни одна механика не требует нового экрана — только состояния `Task`/`Feedback` (правило §1):

| Механика | Где в прототипе |
|---|---|
| **M1 Улика** | evidence strip, подсветка в Улице, 2 улики в Терминале, защита |
| **M2 Стек** | сбор стека 2→3→4 карты, лишняя карта в Системе |
| **M3 Ставка** | low/mid/high, множители, hubris-триггер |
| **M4 Вердикт** | двухшаговый выбор фактора → действие (с L21) |
| **M5 Опознание** | силуэт → портреты домена, эволюция трофея |
| **M6 Play-forward** | график доигрывает 6 свечей, пропуск с 1с |
| **M7 Свиток** | запись «враг,атом,улика», приоритет разминки, мутация сложнее |
| **M8 Комбо** | N=3 совместных применений, двойки/тройки, требование S3–S4 |
| **M9 Слепой** | закрытая вкладка за 6 бюджета, нерелевантная в Терминале |
| **M10 Холодная голова** | вариант ЖДАТЬ всегда, задержка при тильте |
| **M11 Мутация** | seed+hash, 6 осей, шум в III–IV |
| **M12 Кампания** | 3–4 стадии, S3 второй домен, трофей как слои |
| **M13 Погода** | режим дня в топ-баре + баннер |
| **M14 Тень** | распределение ответов, асинхронная тень |
| **M15 Бюджет** | топ-бар, списание/восстановление, Leviathan при 0 |

Эволюция по эпохам видна в `ArenaScene`:
- **Улица L1–20**: ярлыки на всём, подсветка улик, кнопка «К решению», Academy+Arena.
- **Кабинет L21–50**: вердикт, свиток полный, комбо-двойки, слепой источник.
- **Терминал L51–80**: сырые данные, 2 улики, нерелевантный слепой, ложные ярлыки в отдельных заданиях.
- **Система L81–99**: смешанные встречи 2–3 врага, лишняя карта, ложные ярлыки норма, турнир-тень.

### 4. Сцены

**BootScene** — эпоховая заставка, токены из `epochOf(level)`, motto в стиле панк-таблоидной сатиры.

**ArenaScene** — полный цикл:
1. `TopBar` (уровень, XP, SIG, риск-бюджет M15, свиток M7, погода M13, эпоха)
2. `WeatherStrip` M13
3. `QuestionPaper` (учебная цель, нужные карты/атомы, без раскрытия)
4. `UnknownThreat` M5 силуэт 5–8% rim
5. `BrowserShell` (≤3 вкладок, M9 слепой, ярлыки-костыли по эпохе)
6. `EvidenceStrip` M1
7. `CompactSkillCard` (ранг рамкой, ЖДАТЬ M10, режим stack)
8. `AnswerBlock` (standard / sequence M2 / verdict M4 / cold delay M10)
9. `Confidence` M3 → `Feedback` (M6 → M5 → M14 → XP/бюджет/комбо) → `EpochTransition` → `Leviathan` Event

**AcademyScene** — 17 глав, уровни открытия по ТЗ §4.4, атомы-умения, микро-проверки без врагов/источников/наград Арены, ранги рамкой, тизер-силуэт как единственное допустимое присутствие врага (§4.3), gate-экран «что нужно для экзамена».

**CollectionScene** — 3×3 карт + 8 трофеев, пресеты из одного мастера (avatar_circle/card/trophy/banner/popup_v/header_icon), стадии S1–S4 как альфа-слои, свиток M7, калибровка M3, комбо M8.

### 5. Тон и стиль
Тексты в стиле `стиль_тон.txt` — панк-таблоидная сатира: короткие лозунги, псевдоофициальные формулировки («департамент управляемой паники»), чёрный юмор, игрок — соучастник катастрофы. Все фразы типа «ТЫ ЗДЕСЬ РАДИ ДЕНЕГ. РЫНОК УЖЕ ЗАМЕТИЛ ТВОЮ САМОУВЕРЕННОСТЬ».

### 6. Запустить

```bash
cd phaser && npm install && npm run dev   # http://localhost:3000
# прод-сборка
npm run build && npm run preview
```

Управление демо: кнопка **LVL+8** в Arena — прокачивает эпоху без перекомпиляции, показывает снятие костылей и рост навигации.

## 8. Полный юзерфлоу и все страницы (добавлено)

Теперь прототип — сквозной путь «первый вход → Арена». Все страницы зарегистрированы как сцены (`src/config/gameConfig.ts`):

| Сцена | Назначение |
|---|---|
| `OnboardingScene` | первый вход (3 шага), ставит флаг `onboarding_done` |
| `ArenaScene` | задание 4 блока + M1–M15 |
| `AcademyScene` | путь глав + урок (микро-проверка, выдача карты) |
| `CollectionScene` | карты (ранги) + трофеи (стадии-слои) + свиток M7 + калибровка M3 |
| `MoreScene` | профиль + сервисные разделы (Ещё) |
| `ErrorJournalScene` | свиток ошибок M7 |
| `MasteryCheckScene` | готовность к экзамену главы |
| `DailyWarmupScene` | разминка дня (M13 погода + M7 приоритет) |
| `TournamentScene` | турниры / тень M14 |
| `StoreScene` | маркет косметики (SIG только косметика) |
| `SettingsScene` | настройки + сброс → первый вход |

Общий скелет (топ-бар + низ) вынесен в `src/engine/shell.ts`; навигация взрослеет по эпохам (`navForEpoch`).

## 9. Заглушки-рендеры (SVG-база → PNG)

`scripts/gen-placeholders.mjs` генерирует весь placeholder-арт:

```
node scripts/gen-placeholders.mjs
# → public/assets/render/enemies/*   (33 врага x стадии + _icon + _avatar = 182 SVG)
# → public/assets/render/cards/*     (17 карт + Cwait = 18 SVG)
# → public/assets/render/icons/*     (4 nav + 6 домен = 10 SVG)
# → public/assets/manifest.json, icon-index.json
```

Стиль-микс: **10% fight / 30% finance / 30% flat-3D / 30% terminal** (см. `ART_SPEC.md`). Phaser грузит SVG в `BootScene` через `this.load.svg(...)` и растрирует в текстуру — интерфейс проверяется сразу, без ручной сборки PNG.
