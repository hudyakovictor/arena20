9 · Rules

Canonical constraints:
• BottomNav: 4 equal items, no enlarged center
• Browser Widget: largest Arena object, 1–7 source tabs
• Answer options: exactly 4, equal visual weight
• Skill cards: max 4 compact, no combat power
• Enemy hidden until decision — ? / UNKNOWN THREAT
• No HP bar, FOMO meter, Attention Points, fake P&L
• No pay-to-win: boosters, XP accelerators, skill power
• Skin changes chrome only — never enemy/card master art
• Reduced motion is mandatory, not optional
• Touch minimum: 44×44 px · TopBar: 56px · BottomNav: 64px
• Mobile design: 390×844 px · RU-first, i18n from day one
• Raw hex values outside tokens: forbidden
