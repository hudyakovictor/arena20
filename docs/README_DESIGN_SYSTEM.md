# Signal Arena — Terminal Design System 1.0

Canonical UI foundation for the design-stage vertical slice.

## Open the gallery

Open `design-system.html` in any modern browser. It is self-contained and has no network dependencies.

## Files

- `design-system.html` — complete responsive UI Gallery.
- `design-system.tokens.json` — machine-readable tokens and invariant rules.
- `COMPONENT_CONTRACTS.md` — behavior, states and acceptance contracts.

## Technology target

- Phaser 4.2.1
- TypeScript
- Vite
- Mobile-first, RU-first
- PWA-ready

## Canonical constraints represented

- Four equal navigation items.
- Browser Widget as Arena focus.
- Four equal answers.
- Up to four compact skill cards.
- Enemy hidden until the decision.
- No HP, FOMO meter, Attention Points, fake profit or pay-to-win.
- Terminal chrome is independent from enemy/card master art.
- Reduced motion is mandatory.

## Definition of done

The design-system stage is complete when the gallery, tokens, contracts, mobile layout and desktop layout agree. Content population and full page construction are the next product stage, not missing design-system work.
