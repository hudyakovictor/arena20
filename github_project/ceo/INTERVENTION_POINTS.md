# ceo/INTERVENTION_POINTS — где гендиректор смотрит глазами

Гендиректор — единственный человек. Он **не тестирует** (это CI + Reviewer Agent), он **проверяет визуально**, «так ли всё, как я хотел», скачивая проект и открывая его.

## Когда смотреть (CEO-гейты 🔴)
Это задачи в `04_STATUS_LOG.md` с меткой «Гейт» (колонка «Гейт» = 🔴). Их нельзя слить без визуальной приёмки CEO.
По плану (`03_MASTER_PLAN.md`) гейты стоят на ключевых вехах:

| Гейт | Задача | Что смотреть |
|---|---|---|
| M1 · Оболочка | `T012` Top Bar (+ `T013` bottom nav, `T018` sys-states) | Каркас, навигация, токены, системные состояния — «так ли выглядит, как в прототипе?» |
| M1 · График | `T020` CandleChart core (+ `T021`–`T023`) | Свечи, сетка, reveal скрытого future, оверлеи, плавность |
| M2 · Арена | `T040` ArenaScene (+ `T041`–`T047`) | Полный экран задания: текст, вкладки, карты, 4 решения, reveal, вердикт, онбординг |
| M3 · Угрозы | `T060` Grid (+ `T061`/`T062`) | Сетка сущностей, ленивая загрузка, иконки, детальный экран |
| M5 · Голос бренда | `T113` Copy voice | Тексты в tone-of-voice, нет SaaS-заглушек |
| M7 · Релиз | `T132` Release freeze | Финальная приёмка: всё вместе, бюджеты, матрица UI, RU+EN |

## Как смотреть (процедура)
1. Агент/Reviewer Agent довёл CEO-гейт задачу до `review` (CI зелёный, acceptance пройдены).
2. CEO клонирует репо (или качает артефакт сборки), ставит зависимости, `npm run dev` в `client/`.
3. Открывает на мобильном вьюпорте (390×844) и/или в браузере; сверяет с:
   - `signal-arena-prototype(2).html` (UX-карта экранов),
   - `signal-arena-ui-graphics-spec-v1.1.md.md` (токены, иконки, бюджеты),
   - `01_PRODUCT.md` (механика/границы).
4. Решает:
   - **Ок** → пишет «approved», мержит PR (см. `06_REVIEW_WORKFLOW.md`).
   - **Не то** → возврат в `in_progress` + либо правка в том же PR, либо **новая задача** (follow-up, напр. `T040b`), чтобы статус не врал.

## Что НЕ нужно делать CEO
- Не прогонять вручную все тесты — это CI/Reviewer Agent.
- Не лезть в каждую мелкую задачу — только гейты.
- Не менять стек за агентов — только фиксировать гейт/правку.

## Лёгкие внеплановые проверки
CEO может в любой момент попросить spot-чек («проверь ветку phase/4») любого агента — но каноничные точки вмешательства это гейты выше. Между гейтами система едет сама.
