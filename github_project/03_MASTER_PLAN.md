# 03 · MASTER PLAN — от 0% до release-ready

> Сгенерировано из `_meta/tasks.json`. Не редактировать вручную.

Фазы задают продуктовые гейты; реальный порядок работы определяется зависимостями задач, а не номером фазы.

## Фаза 0 — Фундамент и конвенции (Foundation)

**Цель.** Репозиторий, монорепо-каркас, общие схемы, дизайн-токены, пайплайн ассетов, статус-система.

**Результаты:**
- Каркас репозитория (client/shared/admin) + workspace + базовый CI
- Zod-схемы домена (scenario/skill/entity/verdict/profile/protocol/copy)
- Модуль дизайн-токенов (UI_TINT, шрифты, сетка) из UI-спека
- Схема asset-manifest + Zod-валидатор веса/нейминга
- Пайплайн сборки ассетов (SVG→SVGO→атлас, бюджеты в CI)
- Финализированная папка github_project (эта система)

**Точка выхода.** Любой агент может склонировать репо, прочитать github_project/README.md и начать задачу без вопросов.
**Проверка.** CI зелёный: линт, типы, валидация manifest, генерация статус-лога.
**Зависимости фаз.** —
**Параллелизация.** Фаза неделима — делается первой, до неё параллельных треков нет.
**Задачи.** T000, T001, T002, T003, T004, T005

## Фаза 1 — Игровая оболочка (Game Shell) 🔴 CEO-гейт

**Цель.** Phaser 4 boot, единый Canvas, сцены, оболочка (top bar + bottom nav), rexUI-компоненты, Zustand, звук, PWA, системные состояния.

**Результаты:**
- Phaser 4 + Vite, один WebGL-canvas, portrait-scale, game loop
- Архитектура сцен: Boot/Preload/Shell/Router
- Top Bar (rexUI): прогресс, ресурсы, уведомления, помощь, настройки
- Bottom nav 5 слотов (Arena/Academy/Bestiary/Journal/More)
- rexUI-база: panel, button, tabs, list, slider, checklist, modal, toast
- Zustand-store + персист (localStorage)
- Звук (Phaser Sound) + настройки (mute/reduce-motion)
- PWA (vite-plugin-pwa): offline-shell, manifest, иконки
- Системные состояния: loading/offline/empty/error

**Точка выхода.** Пустая оболочка собирается, запускается на мобильном вьюпорте, навигация между заглушками-сценами работает, PWA ставится.
**Проверка.** Vitest (store reducers), Playwright (boot→shell→nav переходы), PWA audit (manifest+sw).
**Зависимости фаз.** Фаза 0
**Параллелизация.** Может идти параллельно с фазой 10 (Backend) после готовности фазы 0.
**Задачи.** T010, T011, T012, T013, T014, T015, T016, T017, T018

## Фаза 2 — Свечной график (CandleChart на Graphics) 🔴 CEO-гейт

**Цель.** Кастомный CandleChart: сетка, свечи из OHLCV, скейлинг, камера, анимация раскрытия скрытого будущего, оверлеи.

**Результаты:**
- CandleChart core: gridGraphics/candleGraphics/overlayGraphics/markerGraphics/maskGraphics/interactionZone
- Reveal скрытого future через mask + tween
- Оверлеи: risk-маркеры, decision-marker, уровни, interaction zone
- Производительность: батченая перерисовка, без Text на каждую свечу
- Юнит-тесты математики/скейлинга (Vitest)

**Точка выхода.** График рисует 40–120 свечей на мобильном, reveal анимируется, FPS≥60, бюджет памяти в норме.
**Проверка.** Vitest (scaling, reveal mask), Playwright (визуал reveal), perf-замер.
**Зависимости фаз.** Фаза 1
**Параллелизация.** Независим от бэкенда.
**Задачи.** T020, T021, T022, T023, T024

## Фаза 3 — Движок сценариев (scenario-gen + seedrandom)

**Цель.** Детерминированный генератор задач: модель данных, seedrandom-PRNG, scenario-gen, адаптация к ошибкам, детерминизм турниров.

**Результаты:**
- Модель исторической ситуации + формат content-pack
- Обёртка seedrandom (seed = scenarioId + contentVersion)
- scenario-gen: детерминированная генерация, сложность 0–99, адаптивный выбор
- Профиль личных ошибок + адаптивная выдача
- Детерминизм турниров (server-fixed seed)
- Тесты: детерминизм, воспроизводимость, кривая сложности

**Точка выхода.** Один seed → один воспроизводимый набор сценариев; повторный прогон даёт идентичный результат.
**Проверка.** Vitest (детерминизм по 1000 seed, совпадение повторов), проверка хэша скрытого future.
**Зависимости фаз.** Фаза 0
**Параллелизация.** Shared-трек; может идти параллельно с фазой 1.
**Задачи.** T030, T031, T032, T033, T034, T035

## Фаза 4 — Игровой цикл Арены (Arena Loop) 🔴 CEO-гейт

**Цель.** Полный цикл задания: текст→браузер-вкладки→карты навыков→4 решения→опц. 2-й шаг→reveal→вердикт→оценка.

**Результаты:**
- ArenaScene: текст задачи, browser-widget с вкладками, карты навыков, 4 кнопки решения, опц. 2-й шаг
- Захват решения + выбор доказательств + принуждение протокола
- Reveal-флоу: рыночный факт → последствие → качество 0–100
- Экран вердикта (панк-таблоид copy)
- Движок оценки (контекст/доказательства/действие/риск/дисциплина)
- Интеграция сущностей (показ/скрытие, раскрытие после разбора)
- Интеграция протоколов
- Onboarding прогрессивного раскрытия
- Playwright e2e полного прохождения Арены

**Точка выхода.** Игрок проходит сценарий от t0 до вердикта с оценкой; оценка не зависит от направления цены.
**Проверка.** Playwright (полный прогон), Vitest (rubric engine), e2e на детерминированном seed.
**Зависимости фаз.** Фаза 1, Фаза 2, Фаза 3
**Параллелизация.** Фронт; зависит от графика (ф2) и движка сценариев (ф3).
**Задачи.** T040, T041, T042, T043, T044, T045, T046, T047, T048

## Фаза 8 — Турниры / PvP (async)

**Цель.** Асинхронные турниры на зафиксированных сервером сценариях; лидерборд; WS.

**Результаты:**
- Список/вход/общий зафиксированный набор/лидерборд
- WS realtime + асинхронная оценка + tie-break по скорости только при равенстве качества

**Точка выхода.** Все участники получают один dataset и одну точку раскрытия; победитель по качеству→протокол→доказательства→скорость.
**Проверка.** Playwright (турнир-флоу), интегра-тест WS против живого сервера.
**Зависимости фаз.** Фаза 3, Фаза 4, Фаза 10
**Параллелизация.** Фронт+бэкенд вместе.
**Задачи.** T080, T081

## Фаза 9 — Маркет (косметика)

**Цель.** Внутренний маркетплейс косметики/тем/сезонов/авторского контента. Без pay-to-win.

**Проверка.** Playwright (открытие/применение косметики), проверка: покупка не влияет на сценарий.
**Зависимости фаз.** Фаза 1
**Параллелизация.** Фронт.
**Задачи.** T090, T091

## Фаза 10 — Бэкенд (Fastify + SQLite + Drizzle + Zod + WS)

**Цель.** Сервер: схема БД, профили/прогресс, отдача сценариев/ассетов, журнал, турниры, античит, контракты API.

**Результаты:**
- Каркас сервера (Fastify), Drizzle, SQLite, миграции, seed
- Профили и персист прогресса
- Отдача сценариев/ассетов + версионность контента + хэш скрытого future
- Персист журнала/результатов + профиль ошибок
- Турнир-сервис + WS
- Античит: server-fixed seeds, защита от утечки future
- Zod-валидация всех API-контрактов + OpenAPI
- Тесты Vitest + Playwright против живого сервера

**Точка выхода.** Клиент может получать сценарии и сохранять прогресс с сервера; детерминизм турниров серверный.
**Проверка.** Vitest (сервисы), Playwright (живой сервер), контракт-тесты Zod.
**Зависимости фаз.** Фаза 0, Фаза 3
**Параллелизация.** Может стартовать параллельно с фазой 1 после фазы 0.
**Задачи.** T100, T101, T102, T103, T104, T105, T106, T107
