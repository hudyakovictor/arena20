# 01 · PRODUCT — что мы строим (конспект)

SIGNAL ARENA — **игровой тренажёр качества торговых решений** на исторических рыночных ситуациях крипторынка.
Не терминал, не демо-счёт, не курс с тестами, не play-to-earn. Главный объект тренировки — **процесс мышления** до/во время/после решения: контекст, риск, неполная информация, когнитивные искажения, эмоции, дисциплина.

> Исчерпывающие спеки лежат в `github_project/source/`: `signal-arena-product-mechanics-spec.md`, `signal-arena-ui-graphics-spec-v1.1.md.md`, `signal-arena-assets-spec.md`, `crypto_competitors_analysis.md`, `style-tone.txt`, `readme.md` (бренд). Этот файл — краткая выжимка для агентов. Спорный момент → читай первоисточник.

## 1. Жёсткие границы (что НЕ делаем)
- Не абстрактная метафора (ферма/город), не симулятор биржи, не копия терминала с декором.
- Не демо-счёт с виртуальным балансом/сделками.
- Не обещаем прибыль/«правильный прогноз»/безубыточность.
- Не play-to-earn (нельзя вывести результат в деньги/токен).
- Нельзя поощрять частоту «сделок», агрессию, виртуальную прибыль.
- Нельзя продавать преимущество в правильности ответа/качестве данных/риск-лимите/базовых защитных навыках.

## 2. Учебная модель (две разные вещи)
- **Механика игры** (onboarding): структура задания, браузер-виджет, карты навыков, 4 решения, оценка вместо победы/поражения, разделы продукта. Короткий, пропускаемый.
- **Теория трейдинга** (Академия): отдельный раздел; связан с практикой (карта→теория→тренировки; ошибка→разбор).

## 3. Основная игровая единица — историческая ситуация
Реальный рыночный отрезок + точка решения `t0`. Игрок видит только то, что могло быть известно до `t0`. После ответа игра **раскрывает заранее зафиксированное** историческое продолжение (не генерирует/не подстраивает).
Типы: **до входа** (есть ли сигнал/входить/сократить риск/остаться вне) и **внутри позиции** (сократить/выйти/ждать подтверждения/признать отмену идеи) — второй обязателен.

## 4. Браузерная модель интерфейса (постоянный каркас)
Top Bar → текст задания → браузерный виджет с вкладками-источниками → карты навыков → 4 кнопки решения → (опц.) нижняя панель 2-го шага.
Вкладки только релевантные (график, старшие ТФ, объём, новости, соц-фон, макро, токеномика, on-chain, история позиции, журнал). Правило: если информация не меняет решение — не показываем.

## 5. Карты навыков
Переносимые принципы «как думать» (чтение/решение/защита). Не магия, не «правильный ответ». Оценивается не сам выбор карты, а соответствие применённого принципа данным и решению.

## 6. Сущности и Угрозы
Игровые воплощения рыночных угроз/искажений/ошибок (33 сущности, имена только на EN): сигналы/структура, эмоции/поведение, нарративы, риск/математика, Web3. На продвинутом уровне сущность скрыта до разбора — игрок учится распознавать паттерн, а не угадывать по иконке монстра.

## 7. Протоколы решения
Режим/ограничение сессии, задающее принцип оценки («Сначала риск», «Только доказательства», «Шумовой карантин» и т.п.). Структура: ситуация + условия + сущность + скиллы + протокол.

## 8. Оценка: не победа и не поражение
После ситуации — 3 слоя: (1) рыночный факт, (2) последствие действия, (3) **качество решения 0–100** (контекст/доказательства/действие/риск/дисциплина). Рыночный исход и качество — разные вещи. Правильное направление не компенсирует грубое нарушение риска. Награда — за качество процесса, не за виртуальный PnL.

## 9. Сложность и уровни 0–99
Каркас не меняется между уровнями (запрет «профильного режима»-терминала). Растёт плотность/конфликты/шум, появляются несколько сущностей, варианты одинаково правдоподобны, вероятностные сценарии без единственного идеала. Уровень 99 недостижим гарантированно (исключительная проверенная дисциплина, без обещания доходности).

## 10. Режимы продукта
Академия · Арена (одиночный, адаптивный) · Угрозы · Журнал решений · Турниры/PvP (асинхронные, server-fixed dataset, победа по качеству→протокол→доказательства→скорость как tie-break) · Маркет (косметика/темы/сезоны/авторский контент, **без pay-to-win**).

## 11. Монетизация и экономика
Коммерческая устойчивость без рекламы брокеров/рефералов/токена. Бесплатный слой: onboarding, база теории, базовые карты защиты, лимит тренировок, базовые сущности, честный разбор, часть турниров. Премиум: глубина/объём/персонализация/авторский контент/косметика/сезоны. Запрещено: покупка ответов/оценки/риск-лимита, лутбоксы, влияющие на качество, обещания доходности.
Внутриигровые ресурсы без денежного выхода. Токен — **не в MVP**, только после proven PMF/комплаенса (product-mechanics-spec §14).

## 12. Честность и античит (исторические данные)
До решения скрываем то, по чему легко найти исход (точная дата, редкое событие, оригинальный заголовок, уникальные цифры, полная ссылка/ID). После — раскрываем проверяемый источник. Для турниров сценарии **server-fixed, воспроизводимы, защищены от утечки future**. Скорость — только при равенстве качества.

## 13. Вертикаль MVP (первый релиз)
Ракета главную механику, не GameFi-обёртку: единый мобильный экран задания, top bar, текст, браузер 3–4 вкладки, 4 кнопки решения, 1 опц. 2-й шаг, 8–12 карт, 6–8 сущностей, **25–40 исторических ситуаций**, reveal продолжения, оценка 0–100, разбор «факт→логика→переносимое правило», базовый профиль повторяющихся паттернов, Академия со связями.
**Не в MVP:** реальный терминал, real-time котировки, кошелёк, выводимые награды, токен, открытый creator-marketplace, сложный PvP, сотни сущностей/карт.

## 14. Tone of voice (стиль)
Панк-таблоидная криптосатира (`style-tone.txt`): коротко, драматично, чёрный юмор, криптожаргон, псевдоофициальные формулировки. Шутка **раскрывает механику**, а не случайный мем. Формула 99/100: пафос + точное наблюдение + саморазоблачение + холодный финальный удар. Запрет neutral-SaaS заглушек в UI (`Victory`, `P&L`, `Continue` без игровой причины). В alpha — никаких token/wallet/airdrop/листинг-разделов.

## 15. Визуал (UI-спец v1.1, кратко)
- Функциональный UI — код/вектор (Graphics, rexUI, Text); растр — там, где худ. ценность (сущности, фоны, косметика, splash).
- 10 цветовых токенов (`UI_TINT`): primary/secondary/muted/active/success/warning/danger/data/noise/narrative.
- Иконки: SVG 24×24 (safe 20×20), stroke 1.5px, `currentColor`→tint, ≤400Б/иконку, core-атлас ≤12КБ. Touch 44×44.
- Бюджеты: first screen ≤250КБ (без Phaser runtime), core UI icon ≤12КБ, раздел дозагрузки ≤600КБ, ≤2.5с до интерактива на среднем Android.
- CandleChart слои: grid/candle/overlay/marker/mask/interactionZone; без Text на каждую свечу; visible 40–120 свечей.
- 33 сущности × (thumb/card/hero/locked/webp + icon svg); first scenario не грузит hero-art.
