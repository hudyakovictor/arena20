# assets/ICON_NOTES — правка иконок (знак vs плашка)

## Замечание гендиректора (исходное)
В архиве `signal_arena_skill_icons_svg.zip` (и в `brand_identity.zip`) часть иконок имеет **знак (глиф) больше, чем плашка/подложка под ним**.
Визуально это «расходится»: знак вылезает за пределы плашки.

## Решение (обязательно для T004/T123)
- **Уменьшить знак**, чтобы он вписывался в safe-area плашки. Не растягивать плашку под знак.
- Соблюдать сетку из UI-спец §3: **24×24, safe-area 20×20, отступ 2px**, stroke 1.5px (1.25px для 16px-версии).
- При необходимости уменьшить знак пропорционально, сохранив читаемость и `currentColor`→tint.

## Проверка (T123, QA-матрица)
Иконка проверяется в 16/20/24/28px, во всех tint-состояниях (active/disabled/warning/danger/data/noise),
на тёмном и светлом локальном фоне, и по touch-target 44×44. Знак не должен выходить за плашку/safe-area.

## Если арт нужно поправить вручную
CEO/художник может доработать исходники позже — это не блокирует сборку (placeholder-стратегия):
реальный svg подставляется в тот же `src` manifest, CI перепроверяет вес/нейминг/габариты.
Агент не ждёт финальный арт, чтобы двинуть вперёд фазу.
