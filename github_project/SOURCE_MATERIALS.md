# SOURCE_MATERIALS — исходники по игре (внутри проекта)

> **Важно.** Вся информация по игре SIGNAL ARENA теперь **физически лежит в папке `github_project/source/`** — рядом с инструкциями, чтобы любой агент, открывший проект, видел и ТЗ, и сами материалы без поиска по репозиторию.
> Для этого репозитория `github_project/source/` — каноническое расположение исходников. Не ищи дубликаты в корне.
> `01_PRODUCT.md` — краткая выжимка; первоисточники ниже обязательны при споре/детали.

## Как агент пользуется исходниками
1. Читает `github_project/README.md` → `01_PRODUCT.md` (конспект).
2. При деталях/споре открывает нужный файл из таблицы (он в `github_project/source/`, рядом).
3. Прототип `source/prototype.html` — это **карта экранов, а не готовая игра**. Агенты строят игру на Phaser по `03_MASTER_PLAN.md`, ориентируясь на прототип визуально.
