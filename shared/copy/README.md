# Copy-keys: мастер-таблица текстов

`keys.tsv` — единый источник всех текстовых ключей интерфейса (RU + EN).
Покрывает 100% строк прототипа `github_project/source/`:
каждый видимый текст экрана имеет ключ, либо зафиксирован в скиплисте
аудита как аннотация/состояние/артефакт (см. `note`, статус `todo`).

## Формат `keys.tsv`

Колонки (таб-разделённые, первая строка — заголовок):

| Колонка  | Смысл                                                                          |
| -------- | ------------------------------------------------------------------------------ |
| `key`    | Имя ключа: латиница/цифры, сегменты через `.`, слоты `{name}`                  |
| `scope`  | `mvp` — нужно сейчас; `later` — после MVP (13.x/14.3/15.2)                     |
| `area`   | Подсистема (первый сегмент ключа): `arena`, `academy`, …                       |
| `screen` | Экран прототипа (`4.11`, `12.2`); пусто для унаследованных                     |
| `ru`     | Русский текст; пусто только при `status=todo`                                  |
| `en`     | Английский текст; пусто = фолбэк на RU в `t()`                                 |
| `status` | `ok` — живой ключ; `draft` — текст из прототипа, не wired; `todo` — текста нет |
| `note`   | Плюрализация, иконки, `REVIEW:`-расхождения с прототипом                       |

Правила:

- Ключ уникален, формат `^[A-Za-z0-9_.@-]+$`.
- Плейсхолдеры `{name}` обязаны совпадать в `ru`/`en` (проверяет генератор).
- Множественное число — в коде по счётчику (`{n} паттерна/паттернов`), не в ключе.
- Иконки/глифы (`▶ ✕ ⚑`) в значениях — только как текстовая заглушка,
  в коде заменяются SVG (помечено в `note`).
- `REVIEW:` — текст ключа осознанно отличается от прототипа
  (ошибка/несогласованность прототипа); решение фиксируется здесь же.
- Контентные ключи (`scen.*`, `skill.*`, `entity.*`) для будущих сущностей
  добавляются по тем же паттернам, пустые строки не фабрикуются.

## Регенерация

```sh
npm run build:copy          # keys.tsv -> shared/src/copy.keys.ts
npm run build:copy -- --check  # только проверка синхронности (CI/тесты)
```

`shared/src/copy.ts` импортирует `RU`/`EN` из generated-файла и хранит
только `t()` / `TAB_LABEL` / `COPY`. Тест `shared/src/copy.test.ts`
падает, если `copy.keys.ts` рассинхронизирован с `keys.tsv`.
