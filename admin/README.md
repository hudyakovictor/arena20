# admin/ — админ-панель и CRM (ПЛАН, не делать в первую очередь)

Управление игрой как контентом + сток всех данных из игры + подключение AI-API.
**Сейчас — только план.** Реализация отдельной итерацией после релиза одиночного продукта (фаза 13, задачи `T130`/`T131`).

- Дорожная карта: [`github_project/admin/ADMIN_ROADMAP.md`](../github_project/admin/ADMIN_ROADMAP.md)
- Трек: [`github_project/tracks/admin.md`](../github_project/tracks/admin.md)

## Зачем
- CEO (гендиректор, единственный человек) может вмешаться в любой процесс, но **без него всё функционирует между агентами**.
- 100% фронт-работ распределяются между агентами как «компания из отделов и чатов»; админка — операционный хаб этой компании.
- Через админку подключаются **API AI-моделей** для генерации контента и распределения задач.

## Рамки (совместимо с продуктом)
- Единый контракт с клиентом/сервером — `shared/` (Zod-схемы). Никакого прямого доступа к БД вне `server/`.
- Границы продукта сохраняются: без pay-to-win, без токена в MVP, честность/античит обязательны. AI-контент проходит Zod + ревью.
